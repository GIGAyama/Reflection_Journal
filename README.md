# 📔 ふりかえりジャーナル

小学校の児童が日々の学びを記録し、先生が閲覧・返却・分析できるWebアプリです。入口はGitHub Pagesの共通URLで、Firebase、学校ごとのGASデプロイ、中央データベースを使いません。

## 仕組み

```text
GitHub Pages（画面・Googleログイン）
  ├─ 児童のGoogle Drive
  │    ├─ 児童ポートフォリオJSON
  │    └─ 添付画像
  │          └─ 先生へ閲覧共有
  └─ 先生のGoogle Drive
       ├─ クラス設定JSON（児童へ非共有）
       └─ 児童別チャンネルJSON
              └─ 対象児童へ閲覧共有
```

- 児童の本文と画像は児童自身が所有し、先生へ直接共有します。
- テーマと先生のおへんじは先生自身が所有し、対象児童へ直接共有します。
- 運営者のGoogleアカウントはデータの所有者にも共有先にもなりません。
- OAuthスコープは `drive.file`。アプリが作成したファイルだけを扱います。
- アクセストークンはメモリ内だけで使い、ブラウザストレージへ保存しません。

詳しい権限境界は [Driveネイティブ設計](docs/DRIVE_NATIVE_ARCHITECTURE.md) を参照してください。

## 主な機能

### 先生

- 複数クラスの作成と切替
- 前回開いたクラスへの復帰
- クラスコード・専用URL・QRコード・招待文のコピー、児童画面プレビュー、QR画像保存
- 参加申請の承認／除外、1人／一括の事前名簿
- 当日テーマと曜日別テーマの配信
- 提出率の円グラフ、検索、返却状況フィルター、本文・画像閲覧
- クイックスタンプ、返却取り消し、本文範囲コメント、一括返却
- Gemini APIによる単件／一括コメント下書きと範囲提案（任意・先生確認必須）
- 今日の提出率、返却数、記述量／気持ちの変化検知
- 14日間の気持ちヒートマップ
- CSV、印刷／PDF出力

### 児童

- QRまたは専用URLから参加
- 端末内の下書き保存
- ルビ付きノート画面、YWT／KPT／5W1H等の型、ランダム書き出し、カテゴリ別ヒント
- カレンダー、テーマ、気持ち、画像添付、提出時の完了演出
- 自分のDriveへの保存と先生への直接共有
- 新着返却通知、過去の記録、全体／本文範囲のおへんじ閲覧
- 1か月以上前の自分へのメッセージ
- PWAインストールと、入力を中断しない更新通知

## 運営者の初期設定

先生や児童のデプロイ作業はありません。運営者だけが共通設定を一度行います。

1. Google Cloudでプロジェクトを作成し、Google Drive APIを有効化します。
2. OAuth同意画面を設定します。
3. OAuthクライアントを「ウェブアプリケーション」で作成します。
4. 承認済みJavaScript生成元へ `https://gigayama.github.io` を登録します。
5. `docs/config.js` の `googleClientId` と `publicEntryUrl` を設定します。
6. GitHub Pagesの公開元を `main` ブランチの `/docs` にします。

学校が18歳未満ユーザーの未構成サードパーティアプリを制限している場合、Workspace管理者が共通OAuthクライアントIDを信頼済みアプリとして許可します。学校ごとのGAS配布やデプロイは不要です。

## 開発

```bash
npm ci
npm run verify
```

`npm run verify` は、QR生成物、Driveデータモデル、Drive REST要求、共有権限、CSV、UI復元マーカー、品質ゲートを検査します。GitHub Actionsではこれに加え、Playwright/Chromiumで児童・教師フローとモバイル／デスクトップ配置回帰を確認します。

主要ファイル：

| ファイル | 役割 |
| --- | --- |
| `docs/index.html` | GitHub Pagesの本番入口 |
| `docs/drive-app.js` | 先生・児童の全画面と操作 |
| `docs/drive-core.js` | データモデル、招待、分析、CSV |
| `docs/drive-api.js` | Google Drive REST API |
| `docs/drive.css` | レスポンシブUIとアクセシビリティ |
| `docs/config.js` | 共通URLとOAuthクライアントID |
| `docs/sw.js` | PWAシェルキャッシュ |

ルート直下に残る `.gs` と旧GAS用HTMLは履歴参照用であり、本番アプリからは読み込まれません。

## 公開前の必須確認

CIではGoogle Workspaceの組織ポリシーを再現できません。個人アカウント2つと、同一学校ドメインの先生・児童アカウントで次を確認してください。

1. 先生がクラスを作成し、専用URLを発行する。
2. 児童が参加し、先生が承認する。
3. 児童が本文と画像を保存する。
4. 先生が本文・画像を閲覧し、コメントを返却する。
5. 児童がテーマと返却コメントを受け取る。
6. ブラウザを閉じた後、再ログインでDrive上のクラスが復元される。

特に、同じOAuthクライアントで別ユーザーが作成・共有したファイルを `drive.file` + `sharedWithMe` で取得できることを確認します。
