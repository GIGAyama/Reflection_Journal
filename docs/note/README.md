
## 貼るまえに直すところ

1. **連載番号**。見出し1行目が `#◯` のままです。前回が #9 なら #10 に置きかえてください。推測で埋めると連載が壊れるので、あえて空けてあります。
2. **公開URLの扱い**。本文の「はじめに」から張っているのは GitHub のリポジトリだけです。先生方に直接ためしてもらえる共通URL（`https://reflection-journal.giga-school.com/`）を運用として公開してよいなら、リポジトリのリンクの下に足してください。開いた先生は自分のドライブに自分のクラスを作るので、他の先生のデータが混ざることはありません。運営アカウントが全クラスのシートに編集者として入る形になるので、そこを引き受けるかどうかで決めてください。
3. **教室での実践の話**。この記事には「使ってみたらこうだった」という記述が一切ありません。作者の実践記録ではないので入れていません。実際に使った場面があれば、「導入のメリット」のあとにでも書き手ご自身の言葉で足してください。

## note への貼りかた

1. note の新規記事を開き、1行目のタイトル欄に `教室で使えるかもしれないもの作り #◯ 「せんせい、なにを書けばいいの」で止まらない。書き出しのことばが出てくるふりかえりアプリ「ふりかえりジャーナル」` を入れます（`#` は付けずに、文字だけ）。
2. 本文は `## 🏫 はじめに` から末尾までをコピーして貼ります。note は `##` を見出しとして受け取り、目次を自動で作ります。
3. 画像は自動では入りません。`![...](images/xx.png)` の行の位置に、対応するファイルを手でアップロードしてください。一覧は下の表のかわりの並びを見てください。
4. 画像のキャプションは、`![]()` の直後に置いてある一文を note のキャプション欄へ移します。本文からは消してかまいません。
5. ハッシュタグの候補は `#GIGAスクール` `#教育ICT` `#小学校` `#ふりかえり` `#GoogleAppsScript` `#教員` あたりです。

## スクリーンショットの撮りかた

正直に書いておきます。**このアプリは、生きている GAS のデプロイと Google のサインインがないと画面が出ません。** 撮影のためだけに本番のクラスを作って、実在しない子どもの記録を書きこむわけにもいきません。そこで、画面を描くコードは本物のまま、サーバー側の応答だけを差しかえて撮りました。

- 読みこんでいるのは `vendor.html` `css.html` `app.html`。つまり `npm run build` が作る本物の生成物です。レイアウト、ふりがな、色、紙吹雪、マーカーの挙動は、先生と子どもが見るものと同じです
- `window.callOwnerApi` と `window.callMemberApi` だけを、架空のクラス「4年1組」を返すものに置きかえています。児童名・本文・メールアドレス・クラスコードはすべて架空です
- 画面の操作は本当に行っています。タブを押す、行にカーソルを乗せる、本文をドラッグして選ぶ、テキストを打つ、提出ボタンを押す。画像の加工や合成は一切していません

撮影環境の都合で、次の2つだけ手当てしています。どちらも見た目を本番に近づけるためのもので、本番の挙動を偽ってはいません。

- **QRコード**。児童用URLを外部サービスへ渡さず、先生のブラウザ内で画像を作ります。画面のQRを読むと、表示されている児童用URLがそのまま開きます
- **フォント**。本番は Google Fonts から Zen Maru Gothic を読みます。同じ woff2 を手もとに置いて読ませました

撮影に使った作業ディレクトリ `.tmp-shots/` は、納品時に消してあります。撮り直すときは、そこに3つのファイルを置きなおしてください。`build-harness.mjs`（本物の生成物と差しかえ用の応答を並べたページを組み立てる）、`mock.js`（架空のクラスのデータ）、`shots.mjs`（どこを押してどこで撮るか）の3つです。用意できたら次を走らせます。

```bash
npm ci
npm i --no-save playwright qrcode
npm run build
node .tmp-shots/build-harness.mjs
node <skill>/scripts/serve.mjs .tmp-shots/site 4180 /        # 別ターミナル
node <skill>/scripts/capture.mjs .tmp-shots/shots.mjs \
     --base http://127.0.0.1:4180/ --out docs/note/images
```

この作業ディレクトリを**リポジトリに残さないでください。** `node_modules` の解決の都合でリポジトリの中に置く必要があるだけのもので、アプリの動作には一切関係しません。撮り終わったら消して、`git status` に残っていないことを確かめてください。

## 文体について踏襲したこと

- 太字・斜体・表を使っていません。Markdown は見出しだけです。note のエディタに素直に貼れることを優先しました
- `→` `／` `：` `▲` `▶` といった記号を本文に入れていません
- 箇条書きは「導入手順」の注意点と「使い方のガイド」の手順だけです。あとは文章で書いています
- 絵文字は見出しにだけ置いています
- デプロイ、テナント、ローカルストレージ、IDトークンといった言葉は出していません。「公開の設定」「その端末のブラウザにだけ残ります」のように言いかえています
- 子どものことは「子どもたち」ではなく、文脈に合わせて「子ども」「その子」と書いています。「児童」は画面の中の表記としてだけ使いました
- 効果は言い切らず、「〜と思っています」「〜はずです」で止めています
- 見出しは基本の6本に、目玉を2本足した構成です。足したのは「💬 スタンプひとつでも、おへんじは返せる」と「💗 気持ちの14日間を、色で見る『心のバイタル』」の2本です
- 結びは #9 と同じ一文にしてあります

本文は約7,200字です。画像が22点あるので、連載のなかでは長めです。見出しで区切ってあるので、読み手は必要なところだけ読めます。
