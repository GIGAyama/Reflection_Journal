# 配布用スプレッドシートを作る（作者向けの手順）

このアプリは、記録を入れるスプレッドシートにスクリプトが束ねられた状態（コンテナバインド）で動きます。
コピーで配ると、先生の手数が **6ファイル貼り付け → デプロイ** から **コピー → デプロイ** に減ります。
この文書は、そのテンプレートを作る手順です。

> **この作業は、Google アカウントを持つ人にしかできません。**
> リポジトリの側からは用意できないので、ここに手順だけ置いてあります。
> テンプレートを作るまで、案内ページの「スプレッドシートをコピーして始める」は効きません
> （`npm run check` が毎回 **G8** の注意でそれを出します）。

---

## 1. テンプレートを作る

1. 新しいスプレッドシートを作り、名前を **「ふりかえりジャーナル」** にする。
   （コピーすると「ふりかえりジャーナル のコピー」になります。先生が名前を変えても構いません。）
2. シートは作らなくてよい。**先生が「はじめの設定」を押したときに `ensureSheets_()` が
   「児童名簿」「ジャーナルデータ」「テーマ設定」「設定」「画像データ」「_meta」を作ります。**
   先に作るなら、見出し行は `Db.gs` の `SHEET_SPECS` と同じにすること。
3. 「拡張機能」＞「Apps Script」を開く。
4. 既定の `コード.gs` の中身を消し、リポジトリの `.gs` を貼り付ける。ファイルは 6 本。

   | Apps Script のファイル名 | 中身をどこから貼るか |
   | --- | --- |
   | `Main` | `Main.gs` |
   | `Db` | `Db.gs` |
   | `Access` | `Access.gs` |
   | `MemberApi` | `MemberApi.gs` |
   | `OwnerApi` | `OwnerApi.gs` |
   | `Gemini` | `Gemini.gs`（正本のコピー。Gemini を使わない学級でも参照があるので必要） |

   `.gs` のファイル名は動作に関係しませんが、そろえておくと直すときに迷いません。
5. 「＋」＞「HTML」で 5 つ作り、名前を **`index` / `app` / `css` / `vendor` / `qr`** にする。
   それぞれリポジトリの同名 `.html` の中身を貼り付ける。
   **`app` / `css` / `vendor` / `qr` は生成物です。** 貼る前に `npm run build` を走らせて、
   原本（`src/app.jsx` など）と一致した状態のものを貼ること。
6. 「プロジェクトの設定」＞「`appsscript.json` マニフェスト ファイルをエディタで表示する」に
   チェックを入れ、リポジトリの `appsscript.json` の中身に置き換える。
   **ここを飛ばすと `oauthScopes` を GAS が推測し、ドライブ全体の権限を要求しはじめます。**
7. いったん保存する。**デプロイはしない**（デプロイはコピーには付いてこないので、
   ここで作っても意味がありません）。

## 2. 中身を空にしておく

**テンプレートに残っているものは、コピーした全員に配られます。**

- 試しに入れた提出・名簿・テーマ・画像を消す
- **「_meta」シートを空にする。** `ownerEmail` が残っていると、コピーした先生が
  「このクラスの先生はすでに ◯◯ で登録されています」と言われて設定できません。
- 「設定」シートに **Gemini の API キーが残っていないか**を必ず確かめる。
  残したまま配ると、あなたのキーで全学級が課金を発生させます。
- スクリプトのプロパティが空か確認する（「プロジェクトの設定」＞「スクリプト プロパティ」）。
  このアプリはスクリプトのプロパティを使いませんが、試作の名残が無いことを見ておく。

> スクリプトのプロパティは**コピーされません**が、テンプレート側に残っていないことは
> 確かめておいてください。

## 3. 共有の設定

1. スプレッドシートの「共有」を開く。
2. 一般的なアクセスを **「リンクを知っている全員」＋「閲覧者」** にする。
   - **「編集者」にしないこと。** 編集者にすると、コピーせずに直接書き込めてしまいます。
3. リンクをコピーする。次の形になっているはずです。

   ```
   https://docs.google.com/spreadsheets/d/<ファイルID>/edit?usp=sharing
   ```

4. 末尾を **`/copy`** に置きかえたものが、配るリンクです。

   ```
   https://docs.google.com/spreadsheets/d/<ファイルID>/copy
   ```

   これを開くと「コピーを作成」のダイアログがすぐ出ます。

## 4. リンクを貼る場所

いまは、どこも **`PUT-TEMPLATE-FILE-ID-HERE`** のままです。ここを差し替えてください。

| ファイル | 場所 |
|---|---|
| `docs/index.html` | 「入れかた」の「スプレッドシートをコピーして始める」ボタン。同じ節の**「配布用スプレッドシートは準備中です」の注意書きも消す** |
| `README.md` | 「手順A：スプレッドシートをコピーする」の手順1 |
| `docs/note/reflection-journal-note-article.md` | 紹介記事の「入れかた」（giga-school.com が翌朝に組み直します） |

**テンプレートを作り直して ID が変わるときも、この3か所すべてを差し替えてください。**
差し替えたら `npm run check` を走らせ、**G8 の注意が消えている**ことを確かめます。

## 5. 入れたあとに確かめること

手元では確かめられないので、実機で1回だけ見てください。

1. **別のアカウント**（できれば学校のアカウント）でコピーリンクを開き、コピーが作れるか。
   - **学校のドメインが「外部のファイルのコピー」を禁じていると、ここで止まります。**
     止まる場合は、手順B（貼り付け）を案内し続けてください。
2. コピーしたファイルの上のメニューに **「ふりかえりジャーナル」** が出るか。
   （このメニューは、スプレッドシートを開いたときに `onOpen` が作ります。）
3. 「はじめの設定」を押し、クラス名を入れると 6 枚のシートができ、
   「_meta」に自分のアドレスが入るか。
4. デプロイし（実行: 自分／アクセス: 同じ組織内の全員）、URL を開いて**先生の画面**が出るか。
5. **児童のアカウント**で同じ URL を開き、参加申請の画面が出るか。承認するまで本体に入れないか。
6. 承認後に 1 件提出し、**コピーしたそのファイル**の「ジャーナルデータ」に行が増えるか。
   （増えなければ `getDb_()` が効いていません。独立スクリプトとして貼られている可能性があります。）
7. 「シートを点検する」を押して「シートの作りは想定どおりです」と出るか。

## 6. すでに配ってある学級について

**配り終えたコピーは、その時点のコードで動き続けます。**
`.gs` を直しても、公開済みの学級には**自動では届きません**。

届けたいときは、この文書の手順1〜2でテンプレートを更新したうえで、
先生方に「Apps Script を開いて該当ファイルを貼り直す」ようお願いすることになります。
**そのお願いをする価値があるのは、記録が壊れる直しだけです。** 見た目の調整で毎回頼まないこと。

貼り直しをお願いするときは、どのファイルを貼り直せばよいかを名指しで書いてください
（`.gs` だけなのか、生成物の `app.html` も要るのか）。
